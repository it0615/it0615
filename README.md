# it0615

**LLM applications · Backend · Model evaluation**

문서에서 근거를 찾고 도구를 호출하는 LLM 서비스를 만듭니다. 모델의 답이 달라지면 검색 결과, 도구 실행, 평가 기준 중 어디에서 차이가 생겼는지 나눠 확인합니다.

### What I work on

- **Retrieval & APIs** — 문서를 검색하고, 답변에 사용한 출처를 확인할 수 있는 API를 설계합니다.
- **LLM agents** — 자연어 요청을 도구 호출과 연결하고 Docker 환경에서 실행 흐름을 검증합니다.
- **Evaluation** — 보기 순서처럼 평가 조건을 하나씩 바꿔 모델이 실제로 고른 답이 달라지는지 비교합니다.
